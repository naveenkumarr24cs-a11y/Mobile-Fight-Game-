# Mobile Fight Game

Welcome to the **Mobile Fight Game**! 

This is a 2D fighting game designed specifically for Android devices, completely written in Kotlin using Android Studio. It features dynamic character controls, combo systems, intelligent AI, and mobile-optimized graphics.

## Features
- **Intelligent AI**: Smart enemy combatant that reacts to the player's position, tracks hit-stuns, and uses combos.
- **Dynamic Controls**: Optimized on-screen joystick and attack buttons (Light, Heavy, Combo, Roll, Block).
- **Responsive Layout**: Designed to look great on all mobile device sizes, including curved displays, with an immersive full-screen edge-to-edge experience.
- **Audio & Visual Effects**: Built-in sound effects and particle/stun animations.

## Setup Instructions
1. Open this project in **Android Studio**.
2. Sync the project with Gradle files.
3. Build the APK via **Build > Build Bundle(s) / APK(s) > Build APK(s)** or click the **Run** button to test it on your Android Emulator or physical device.

## Technologies Used
- Kotlin
- Android SDK
- Gradle

Enjoy fighting!
